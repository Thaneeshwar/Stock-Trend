# 📈 Statistical vs Machine Learning Stock Trend Prediction

An interactive Streamlit web application that compares classical statistical time-series models (ARIMA) against machine learning classifiers for predicting next-day stock price direction.

## ✨ Features

- **Interactive 3D Visualizations**: Price landscapes, volume flow, and feature spaces
- **Statistical Modeling**: ARIMA with 95% confidence intervals
- **Machine Learning**: Logistic Regression, Random Forest, Gradient Boosting
- **Comprehensive Comparison**: Side-by-side model evaluation
- **Educational Content**: Learn about probability and statistics in finance

## 🛠️ Tech Stack

- **Frontend**: Streamlit
- **Data Processing**: Pandas, NumPy
- **Visualization**: Plotly (3D interactive charts)
- **Financial Data**: yfinance
- **Statistical Modeling**: statsmodels
- **Machine Learning**: scikit-learn
